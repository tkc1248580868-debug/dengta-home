# Security Policy

## Supported version

Only the latest commit on `main` receives security fixes during the current development phase.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private security advisory flow. Do not publish credentials, user data, private endpoints, database dumps or reproduction tokens in a public Issue.

Include:

- affected component and commit;
- minimal reproduction steps;
- expected and observed behavior;
- impact and any suggested mitigation.

## Deployment responsibility

This repository contains self-hosting source code. Operators are responsible for access control, secret rotation, database backups, CORS policy, provider terms and platform monitoring in their own deployment.
