# DengTa Home

DengTa Home 是围绕长期陪伴与连续对话构建的移动应用体验。

## Language

**核心聊天流程**:
用户从打开 App 到完成一轮对话的连续体验，包含查看聊天与天气、展开或收起动态栏、输入并发送消息，以及看见 AI 回复。该流程的可用性优先于装饰效果和次要页面。
_Avoid_: 主流程、基础流程

**动态栏**:
聊天页顶部用于查看和发起陪伴互动的状态区域，具有紧凑状态和展开状态。重新进入聊天页时以紧凑状态呈现。
_Avoid_: 系统状态栏、通知栏

**会话模型**:
绑定到单个聊天会话并从下一条消息开始持续使用的模型选择。已有消息不受后续切换影响，新会话从 App 默认模型开始。
_Avoid_: 全局模型、单次模型

**引用回复**:
本轮消息以一条既有的用户消息或 AI 正式回复作为明确背景。一次只能保留一条引用，选择另一条时替换原引用；发送后保留当时的文字快照，原消息不可用时历史含义仍保持不变。
_Avoid_: 转发、多选引用

**聊天建议**:
在当前会话具有足够语境且最新 AI 回复存在明确回应空间时，提供给用户选择的候选回复。语境不足或候选无法锚定当前人物、动作或情绪时，该区域不存在。
_Avoid_: 固定话术、默认按钮

**天气卡**:
聊天页中展示当前时间与天气背景的可缩略环境信息区域。它记住用户的展开或缩略选择，不与动态栏的重置规则共用状态。
_Avoid_: 动态栏、系统天气通知

**个性化指令与用户详情**:
用户分别保存在“个性化指令”和“你的详情”中的长期原文。两者不做语义解析或首尾裁剪，并在每轮请求中共同进入 App 可控范围内最高应用级的 instructions / system；它们不被动态记忆或本轮信息自动改写。
_Avoid_: 主系统提示词、普通聊天消息、破甲词

**稳定记忆**:
经过用户确认、用于维持长期关系连续性的经历摘要。它补充个性化指令与用户详情，但不能覆盖或修改这两项用户原文。
_Avoid_: 原始聊天记录、临时背景

**本轮背景**:
只与当前消息有关的天气、状态、引用、临时补充或检索结果。它仅服务本轮理解，不自动成为稳定记忆。
_Avoid_: 固定人设、长期记忆

**本轮上下文核验**:
用于确认个性化指令、用户详情、稳定记忆、最近历史和本轮背景是否按预期装配的回执。回执只展示是否发送、顺序和字数，不包含两项用户原文、记忆正文、密钥或隐藏思维链。
_Avoid_: 思维链、接口密钥日志

**温馨档案风**:
DengTa Home 的统一视觉语言，保留小灯大熊与桃桃小猫的角色背景，并使用书刊式标题、手写短句、细线和标签化信息层级。它借鉴参考图的排版方法，但不复刻其完整页面或单一米白配色。
_Avoid_: 参考图复刻、纯复古主题

**原生手感层**:
覆盖在全部既有功能之上的统一材质与运动规范。开场、页面、弹层、动态栏、天气卡和输入区只能用不会改变布局的合成动画；实时模糊只用于少量固定浮层，重复列表项使用近似透明材质而不逐项模糊。
_Avoid_: 功能重写、长列表逐项模糊、持续描边动画

**用户**:
拥有独立私密数据的已注册使用者。每位用户默认拥有一个 AI 伴侣，并可以通过付费获得更多伴侣名额。
_Avoid_: Owner、访客

**AI 伴侣**:
归属于一个用户、拥有独立人设、稳定记忆和关系历程的长期陪伴角色。不同伴侣之间不得共享私密上下文。
_Avoid_: 模型、聊天会话

**聊天会话**:
隶属于一个 AI 伴侣的连续消息线程。多个会话共享该伴侣的人设与稳定记忆，但各自保留独立的近期聊天历史和引用关系。
_Avoid_: AI 伴侣、独立人设

**伴侣名额**:
允许用户创建一个额外 AI 伴侣的账号权益。第一版通过兑换码或管理员授予，不包含任何模型调用额度。
_Avoid_: 模型额度、API 余额

**本机 MCP 连接**:
由安装版 App 所在设备直接访问的 MCP 连接，可以在明确警告后使用局域网地址、明文连接或自定义端口。其风险和可达范围局限在当前用户设备。
_Avoid_: 云端 MCP 连接、共享代理

**云端 MCP 连接**:
由 DengTa Home 共享后端代表当前用户访问的 MCP 连接，只能使用经过网络边界保护的公网服务。每条连接及凭据严格归属于创建它的用户。
_Avoid_: 本机 MCP 连接、任意 URL 代理
